Effects only, transparent background. Paste this link into an OBS Browser Source (1920×1080).
How to add it in OBS

1. In OBS: Sources → + → Browser. Paste the link above in URL (or tick Local file and pick this file, then add ?overlay to the path). Width 1920, height 1080.

2. Keep this panel open in your normal browser, or add it in OBS via Docks → Custom Browser Docks (same link without ?overlay). The status above turns green when the overlay is connected.

If they don't connect from a local file, start python -m http.server in the folder and use http://localhost:8000/index.html for both.
